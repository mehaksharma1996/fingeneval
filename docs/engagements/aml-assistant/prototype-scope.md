# Prototype scope

The vertical slice loads one AML project, two registered system versions, an approved six-case pack, and a versioned release policy. It runs a credential-free comparison, persists case evidence, detects one critical deadline regression, creates a finding, computes `BLOCK`, records human review, registers remediation, executes a targeted rerun, resolves the finding, computes an updated decision, and creates a hashed Markdown handoff report.

Excluded from this slice: production identity, uploads, generic dataset authoring, distributed queue, real customer policies, provider deployment, notification/webhook delivery, and external compliance assessment.
