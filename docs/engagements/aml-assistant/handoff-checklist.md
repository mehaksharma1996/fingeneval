# Handoff checklist

- [x] Intended/prohibited use, owners, and critical risk tier recorded
- [x] Baseline, candidate, dataset, and policy versions bound to the run
- [x] Credential-free critical-regression demo and automated test
- [x] Deterministic rule trace and incomplete-run guard
- [x] Finding, reviewer action, remediation, targeted rerun, and report audit events
- [x] Architecture, API, threat model, responsible AI, deployment, and runbook
- [ ] Production identity and separation-of-duties approval
- [ ] Entitlement-aware document ingestion/retrieval
- [ ] Durable queue and provider budgets
- [ ] Calibrated real-model evaluation with human labels
- [ ] Security/privacy/legal reviews and incident exercise
- [ ] Representative scale/resilience test and go-live SLOs
