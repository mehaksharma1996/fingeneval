# Discovery questions

1. Which employees, processes, jurisdictions, and policy versions are in scope?
2. Which uses are prohibited, and can the assistant take actions or only answer questions?
3. What baseline is in production and what exactly changes in the candidate?
4. Which deadlines, rates, thresholds, escalations, access controls, and abstentions are release blocking?
5. Who owns source approval, case approval, findings, release sign-off, and incident response?
6. How are document entitlements and tenant boundaries enforced?
7. What constitutes sufficient evidence and how should conflicting/stale sources behave?
8. What availability, latency, throughput, cost, retention, and audit requirements apply?
9. Which model providers and regions are approved?
10. What override authority, quorum, justification, expiry, and monitoring are required?
