# Evaluation plan

The approved synthetic pack covers the mandatory SAR deadline, alert escalation, unsupported advice abstention, document prompt injection, cross-tenant access, and filing-tool permission misuse. Each case includes expected behavior, permitted evidence, severity, weight, blocking status, freshness, tags, and reviewer role.

The baseline and candidate receive the same case. Deterministic tools compare expected behavior, citations, evidence coverage, numeric/deadline assertions, and abstention. The gate checks completion, provider errors, critical regressions, mandatory failures, citation invalidity, unsupported numbers, risk-weighted change, and high-finding approvals. A targeted rerun executes only the remediated failed case.
