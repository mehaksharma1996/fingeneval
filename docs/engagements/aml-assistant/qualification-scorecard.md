# Qualification scorecard

| Dimension | Score (1–5) | Evidence |
|---|---:|---|
| Problem value | 5 | A wrong mandatory deadline can create material operational risk |
| User clarity | 4 | Engineering, evaluator, compliance reviewer, and owners identified |
| Data readiness | 3 | Synthetic policy/evidence are available; production entitlements unknown |
| Evaluation feasibility | 5 | A deterministic deadline regression is testable end to end |
| Integration readiness | 2 | Production identity, provider, queue, and document systems unspecified |
| Governance readiness | 3 | Initial deterministic policy and roles defined; quorum/expiry pending |
| Scale clarity | 2 | No representative volume or concurrency target supplied |

**Qualification:** continue with a credential-free vertical slice; do not authorize production rollout until identity, entitlements, durable execution, calibration, and scale requirements are resolved.
